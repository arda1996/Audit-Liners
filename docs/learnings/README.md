# Learnings (otomatik bağlam)

Bu klasördeki `.md` dosyaları, dosya adındaki anahtar kelimeler kullanıcının istemiyle eşleştiğinde
`user-prompt-inject-context.sh` tarafından **otomatik** olarak bağlama eklenir.
İlgisiz olduklarında sıfır token maliyeti olur.

İsimlendirme: konuyu dosya adına koyun, ör. `database-migrations.md`, `auth-flow.md`, `deployment.md`.
